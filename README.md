# 💬 AnonChat — Real-Time Anonymous Messaging Platform

![Firebase](https://img.shields.io/badge/Firebase-RealtimeDB-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)
![JavaScript](https://img.shields.io/badge/Frontend-ES6+_Vanilla-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![CSS3](https://img.shields.io/badge/Styling-Cyberpunk_Neon_UI-1572B6?style=for-the-badge&logo=css3&logoColor=white)

> **AnonChat** is a lightweight, zero-latency real-time anonymous chatting platform featuring a modern cyberpunk/neon theme. Built with Firebase Realtime Database and native Web APIs for instant room-based communication.

---

## ✨ Features

- ⚡ **Instant Real-Time Sync**: Instant message delivery backed by Firebase Realtime Database.
- 🔒 **Privacy-First Messaging**: No mandatory user registration. Anonymous session handles & custom room access codes.
- 🎨 **Cyberpunk Neon UI**: Custom dark mode layout with glowing status indicators.
- 📱 **Mobile-First Responsive**: Fluid layouts adapted across desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid), ES6+ JavaScript.
- **Database & Backend**: Firebase Realtime Database SDK.

---

## 🚀 Installation & Local Running

1. **Clone repo**:
   ```bash
   git clone https://github.com/jobayerhossain-ai/annochat.git
   cd annochat
   ```
2. **Launch Application**:
   Open `index.html` in any web browser or serve with Live Server.
